Pipeline Operations Manager

EPIC-3 — Infrastructure Lifecycle Management
Design Document | April 2, 2026 | Build 388

Overview

The Pipeline Operations Manager is an AI agent that manages infrastructure lifecycle for ChatHealthy.ai data pipelines. It manages clusters, not data. It reads errors, not records. It escalates to the right person, not fixes code.

The agent uses tools. Tools don't think. The agent thinks.

Diagnose Loop Detail

GPT-4.1-mini iterates up to N times (configurable, default 3). Each iteration it can call tools to gather evidence:

Tool CallWhat It ReturnsWhy
ClusterTool.status()Cluster state, connection healthIs the DB even reachable?
AlertTool.read_recent()Last N log entriesWhat happened before the error?
ClusterTool.check_connection()Connection test resultNetwork or auth problem?

After gathering evidence, GPT-4.1-mini classifies:

VerdictEvidence RequiredNext Step
InfrastructureCluster down, connection failed, timeoutSelf-repair → if fails → Escalate Boss
Pipeline LogicSchema mismatch, data format error, business rule violationSend to Dev Manager with evidence
Can't DetermineMax iterations reachedEscalate Boss directly
